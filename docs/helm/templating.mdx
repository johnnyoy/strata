# Helm Templating

<Level show="short">
Helm templates are Go templates. Values from `values.yaml` are injected via `{{ .Values.key }}`.

```yaml
# templates/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Release.Name }}-app
  labels:
    app: {{ .Values.appName }}
spec:
  replicas: {{ .Values.replicaCount | default 1 }}
```

```bash
helm template my-release ./my-chart   # render without installing
helm install my-release ./my-chart --dry-run --debug
```
</Level>

<Level show="medium">
**Chart directory structure**

```
my-chart/
├── Chart.yaml          # name, version, appVersion, dependencies
├── values.yaml         # default values
├── templates/
│   ├── _helpers.tpl    # named templates (no output)
│   ├── deployment.yaml
│   ├── service.yaml
│   └── NOTES.txt       # displayed after helm install
└── charts/             # sub-chart tarballs (helm dependency update)
```

**Built-in objects**

| Object | Examples |
|--------|---------|
| `.Release` | `.Release.Name`, `.Release.Namespace`, `.Release.IsInstall` |
| `.Chart` | `.Chart.Name`, `.Chart.Version`, `.Chart.AppVersion` |
| `.Values` | anything from `values.yaml` or `--set` |
| `.Files` | `.Files.Get "config.json"` |
| `.Capabilities` | `.Capabilities.KubeVersion.Major` |

**Control flow**

```yaml
# if / else
spec:
  {{- if .Values.autoscaling.enabled }}
  replicas: {{ .Values.autoscaling.minReplicas }}
  {{- else }}
  replicas: {{ .Values.replicaCount }}
  {{- end }}
```

```yaml
# range — iterate over a list or dict
env:
  {{- range .Values.extraEnv }}
  - name: {{ .name }}
    value: {{ .value | quote }}
  {{- end }}
```

**`toYaml | nindent` — rendering nested YAML**

```yaml
# values.yaml
resources:
  limits:
    cpu: 500m
    memory: 128Mi

# templates/deployment.yaml
resources:
  {{- toYaml .Values.resources | nindent 10 }}
```

**Named templates in `_helpers.tpl`**

```yaml
{{/* Standard labels — reuse across all resources */}}
{{- define "mychart.labels" -}}
app.kubernetes.io/name: {{ .Chart.Name }}
app.kubernetes.io/instance: {{ .Release.Name }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
{{- end }}

# In any template:
metadata:
  labels:
    {{- include "mychart.labels" . | nindent 4 }}
```

**`with` — scoped context**

```yaml
{{- with .Values.ingress }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ $.Release.Name }}-ingress  # $ = root context
spec:
  rules:
    - host: {{ .host }}               # . = .Values.ingress
{{- end }}
```
</Level>

<Level show="long">
**Template whitespace control**

`{{-` strips whitespace/newlines before the action; `-}}` strips after. Misuse produces malformed YAML.

```yaml
spec:
  containers:
    {{- range .Values.containers }}   # no blank line before range output
    - name: {{ .name }}
    {{- end }}
```

**Sprig functions** (extended template library bundled with Helm)

```yaml
{{ .Values.name | upper }}               # "MY-APP"
{{ .Values.name | trunc 20 | trimSuffix "-" }}
{{ .Values.timeout | default 30 }}
{{ .Values.password | b64enc | quote }}  # base64 encode
{{ randAlphaNum 16 | b64enc }}           # random 16-char string
{{ now | date "2006-01-02" }}            # Go reference time format
```

**Required and fail**

```yaml
{{ required "values.image.tag is required" .Values.image.tag }}
{{ if not .Values.image.tag }}{{ fail "must set image.tag" }}{{ end }}
```

**Chart dependencies**

```yaml
# Chart.yaml
dependencies:
  - name: postgresql
    version: "15.x.x"
    repository: https://charts.bitnami.com/bitnami
    condition: postgresql.enabled   # only install if values.postgresql.enabled=true
    alias: db                       # access values at .Values.db.*
```

```bash
helm dependency update ./my-chart   # download deps into charts/
helm dependency list ./my-chart     # show dependency status
```

**Testing charts**

```yaml
# templates/tests/test-connection.yaml
apiVersion: v1
kind: Pod
metadata:
  name: "{{ .Release.Name }}-test"
  annotations:
    "helm.sh/hook": test
spec:
  containers:
    - name: wget
      image: busybox
      command: ["wget", "--spider", "http://{{ .Release.Name }}:{{ .Values.service.port }}"]
  restartPolicy: Never
```

```bash
helm test my-release   # runs all test hooks
```

**`lookup` function — query live cluster state**

```yaml
{{- $secret := lookup "v1" "Secret" .Release.Namespace "my-secret" -}}
{{- if $secret }}
  # secret already exists — don't regenerate
{{- else }}
  # create new secret
{{- end }}
```

**Packaging and publishing**

```bash
helm lint ./my-chart              # validate chart structure
helm package ./my-chart           # creates my-chart-1.0.0.tgz
helm push my-chart-1.0.0.tgz oci://ghcr.io/my-org/charts
```
