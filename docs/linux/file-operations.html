Linux File Operations

find — search the filesystem

# By name
find . -name "*.py"                    # case-sensitive
find . -iname "*.PY"                   # case-insensitive

# By type
find . -type f                         # files only
find . -type d                         # directories only
find . -type l                         # symlinks only

# By time
find . -mtime -7                       # modified < 7 days ago
find . -mtime +30                      # modified > 30 days ago
find . -newer reference.txt            # newer than reference file

# By size
find . -size +100M                     # larger than 100MB
find . -size -1k                       # smaller than 1KB

# Execute a command on results
find . -name "*.log" -exec rm {} \;    # delete matching files
find . -name "*.log" -exec gzip {} +  # gzip (faster: batches args)
find . -name "*.py" | xargs grep "TODO"  # grep in found files

tar — archiving

# Create
tar -czf archive.tar.gz dir/           # create gzip-compressed
tar -cjf archive.tar.bz2 dir/          # bzip2
tar -cJf archive.tar.xz dir/           # xz (smaller, slower)
tar -cf archive.tar dir/               # uncompressed

# Extract
tar -xzf archive.tar.gz                # to current dir
tar -xzf archive.tar.gz -C /target/   # to specific dir

# List contents
tar -tzf archive.tar.gz

# Extract single file
tar -xzf archive.tar.gz path/to/file

rsync — efficient file sync

rsync -av src/ dest/                   # local sync
rsync -av src/ user@host:/dest/        # to remote
rsync -av user@host:/src/ dest/        # from remote
rsync -av --delete src/ dest/          # mirror (delete extra files in dest)
rsync -av --exclude="*.log" src/ dest/ # exclude pattern
rsync -av --dry-run src/ dest/         # preview without applying
rsync -avz src/ user@host:/dest/       # compress in transit

Note: src/ (trailing slash) = sync contents of src. src (no slash) = sync the src directory itself.

Disk usage

du -sh *                               # size of each item in current dir
du -sh /var/log/*                      # size of each item in /var/log
du -sh --max-depth=1 /                 # top-level dirs on /
du -h /var/log | sort -h | tail -20   # 20 largest items

df -h                                  # filesystem usage
df -h /var/log                         # specific filesystem
df -i                                  # inode usage
