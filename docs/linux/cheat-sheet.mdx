# Linux Cheat Sheet

<CheatSection title="Permissions & Ownership">

| Command | What it does |
|---------|-------------|
| `chmod 755 file` | rwxr-xr-x |
| `chmod 644 file` | rw-r--r-- |
| `chmod +x script.sh` | Add execute for all |
| `chmod -R 755 dir/` | Recursive |
| `chown alice file` | Change owner |
| `chown alice:devs file` | Owner + group |
| `chown -R alice:devs dir/` | Recursive |
| `umask 022` | Default new file mask |

</CheatSection>

<CheatSection title="Processes">

| Command | What it does |
|---------|-------------|
| `ps aux` | All processes snapshot |
| `pgrep nginx` | PIDs by name |
| `kill 1234` | SIGTERM (graceful) |
| `kill -9 1234` | SIGKILL (force) |
| `pkill -f "python app"` | Kill by command line |
| `nice -n 10 cmd` | Start with lower priority |
| `nohup cmd &` | Run immune to hangup |
| `jobs` / `fg %1` / `bg %1` | Manage background jobs |

</CheatSection>

<CheatSection title="Systemd">

| Command | What it does |
|---------|-------------|
| `systemctl status nginx` | Show service status |
| `systemctl start \| stop \| restart nginx` | Lifecycle |
| `systemctl enable \| disable nginx` | Boot persistence |
| `journalctl -u nginx -f` | Follow service logs |
| `journalctl -u nginx --since "1h ago"` | Time-filtered logs |
| `systemctl list-units --failed` | Failed services |

</CheatSection>

<CheatSection title="Shell">

| Syntax | Meaning |
|--------|---------|
| `cmd1 \| cmd2` | Pipe stdout to next command |
| `cmd > file` | Redirect stdout (overwrite) |
| `cmd >> file` | Redirect stdout (append) |
| `cmd 2>&1` | Redirect stderr to stdout |
| `cmd &>/dev/null` | Discard all output |
| `cmd1 && cmd2` | Run cmd2 only if cmd1 succeeds |
| `cmd1 \|\| cmd2` | Run cmd2 only if cmd1 fails |
| `$(cmd)` | Command substitution |
| `${VAR:-default}` | Use default if VAR is unset |

</CheatSection>

<CheatSection title="Networking">

| Command | What it does |
|---------|-------------|
| `curl -s -o /dev/null -w "%{http_code}" URL` | HTTP status code |
| `curl -L -O URL` | Download following redirects |
| `ss -tlnp` | TCP listening ports + processes |
| `ss -tnp` | Established TCP connections |
| `dig example.com +short` | DNS lookup |
| `nc -zv host 443` | Test if port is open |
| `ping -c 4 host` | Reachability test |
| `traceroute host` | Hop-by-hop path |

</CheatSection>

<CheatSection title="File Operations">

| Command | What it does |
|---------|-------------|
| `find . -name "*.log" -mtime -7` | Recent log files |
| `find . -size +100M -type f` | Large files |
| `find . -name "*.tmp" -delete` | Delete matching files |
| `tar -czf archive.tar.gz dir/` | Create archive |
| `tar -xzf archive.tar.gz -C /dest/` | Extract |
| `rsync -av --delete src/ dest/` | Mirror sync |
| `rsync -avz src/ user@host:/dest/` | Remote sync |
| `du -sh *` | Disk usage per item |
| `df -h` | Filesystem usage |

</CheatSection>
