# Linux Shell

<Level show="short">
```bash
command1 | command2    # pipe: stdout of 1 → stdin of 2
command > file         # redirect stdout to file (overwrite)
command >> file        # append stdout to file
command 2>&1           # redirect stderr to stdout
command1 && command2   # run 2 only if 1 succeeds
command1 || command2   # run 2 only if 1 fails
$(command)             # command substitution
$VAR                   # variable expansion
```
</Level>

<Level show="medium">
**Pipes and redirection**

```bash
# Pipes
ls -la | grep ".log" | wc -l      # count log files
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn

# Redirect stdout
command > output.txt          # overwrite
command >> output.txt         # append

# Redirect stderr
command 2> errors.txt         # stderr only
command > output.txt 2>&1     # both stdout and stderr
command &> output.txt         # bash shorthand for above
command 2>/dev/null           # suppress errors

# /dev/null
command > /dev/null 2>&1      # discard all output

# Here-doc
cat <<EOF
line 1
line 2
EOF
```

**Variables**

```bash
NAME="Alice"
echo "Hello, $NAME"
echo "Hello, ${NAME}!"     # braces required before non-separator chars

# Command substitution
TODAY=$(date +%Y-%m-%d)
FILES=$(ls *.log | wc -l)

# Arithmetic
COUNT=$((COUNT + 1))
echo $((2 ** 10))           # 1024

# Special variables
$0    # script name
$1    # first argument
$@    # all arguments (as separate words)
$#    # number of arguments
$?    # exit code of last command
$$    # PID of current shell
```

**Conditionals**

```bash
if [ "$VAR" = "hello" ]; then
  echo "match"
elif [ "$VAR" = "world" ]; then
  echo "other"
else
  echo "neither"
fi

# File tests
if [ -f file.txt ]; then echo "file exists"; fi
if [ -d /tmp ]; then echo "directory exists"; fi
if [ -z "$VAR" ]; then echo "variable is empty"; fi
if [ -n "$VAR" ]; then echo "variable is set"; fi

# Numeric comparison
if [ $COUNT -gt 5 ]; then echo "more than 5"; fi
# -eq -ne -lt -le -gt -ge
```

**Loops**

```bash
for f in *.log; do
  echo "Processing $f"
  gzip "$f"
done

for i in {1..10}; do echo $i; done

while read line; do
  echo "Line: $line"
done < input.txt
```

<Level show="long">
**quoting rules**

Single quotes preserve everything literally. Double quotes expand variables and `$()` but preserve spaces. No quotes splits on spaces and expands globs.

```bash
echo '$HOME'          # literal: $HOME
echo "$HOME"          # expanded: /home/alice
echo ~                # expanded: /home/alice (glob)
echo "it's fine"      # apostrophe inside double quotes: fine
echo 'say "hello"'    # quotes inside single quotes: fine
```

Always double-quote variables to prevent word splitting and glob expansion:

```bash
# Bad: breaks if filename has spaces
for f in $(ls); do cp $f /backup; done

# Good
while IFS= read -r f; do cp "$f" /backup; done < <(find . -name "*.log")
```

**Process substitution**

`<(command)` creates a named pipe that looks like a file:

```bash
diff <(sort file1) <(sort file2)          # diff sorted versions
while IFS= read -r line; do              # read from command output
  process "$line"
done < <(find . -name "*.py")
```

**`set` options for robust scripts**

```bash
#!/bin/bash
set -euo pipefail

# -e  exit on any error
# -u  treat unset variables as errors
# -o pipefail  pipe fails if any command in it fails
```

This is the standard header for production shell scripts. Without it, a failed command is silently ignored.

**Functions**

```bash
greet() {
  local name="$1"           # local scoping — doesn't pollute global namespace
  echo "Hello, $name"
  return 0                  # explicit return code
}

greet "Alice"
echo "Exit: $?"
```

**Traps (cleanup on exit)**

```bash
cleanup() {
  rm -f /tmp/my-tempfile
  echo "Cleaned up"
}
trap cleanup EXIT              # run on any exit (normal or error)
trap 'echo "interrupted"' INT  # run on Ctrl+C
```

**Arrays**

```bash
FILES=("a.txt" "b.txt" "c.txt")
echo "${FILES[0]}"            # first element
echo "${FILES[@]}"            # all elements
echo "${#FILES[@]}"           # count

for f in "${FILES[@]}"; do
  echo "$f"
done
```

**Useful parameter expansions**

```bash
${VAR:-default}    # use "default" if VAR is unset or empty
${VAR:=default}    # assign "default" to VAR if unset
${VAR:?error msg}  # exit with error if VAR is unset
${VAR#prefix}      # remove shortest prefix match
${VAR##prefix}     # remove longest prefix match
${VAR%suffix}      # remove shortest suffix match
${VAR%%suffix}     # remove longest suffix match
${VAR/old/new}     # replace first occurrence
${VAR//old/new}    # replace all occurrences
${#VAR}            # length of VAR

# Example: strip extension
file="report.tar.gz"
echo "${file%%.*}"   # report
echo "${file##*.}"   # gz
```

**Debugging scripts**

```bash
bash -x script.sh        # trace execution (print each command)
bash -n script.sh        # syntax check only (no execution)
set -x                   # enable trace inside script
set +x                   # disable trace
```

ShellCheck (`shellcheck script.sh`) catches common pitfalls — run it in CI.
