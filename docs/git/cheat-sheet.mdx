# Git Cheat Sheet

<CheatSection title="Setup">

| Command | What it does |
|---------|-------------|
| `git config --global user.name "Alice"` | Set name |
| `git config --global user.email "a@example.com"` | Set email |
| `git init` | Init new repo |
| `git clone URL` | Clone remote repo |
| `git clone URL --depth 1` | Shallow clone (no history) |

</CheatSection>

<CheatSection title="Staging & Commits">

| Command | What it does |
|---------|-------------|
| `git status` | Working tree status |
| `git add file` | Stage file |
| `git add -p` | Stage interactively (hunks) |
| `git diff --cached` | Diff between index and last commit |
| `git commit -m "message"` | Commit staged changes |
| `git commit --amend` | Rewrite last commit (before push only) |
| `git log --oneline` | Compact history |
| `git show <sha>` | Show commit contents |

</CheatSection>

<CheatSection title="Branching">

| Command | What it does |
|---------|-------------|
| `git branch` | List local branches |
| `git checkout -b feature` | Create + switch |
| `git switch feature` | Switch (modern syntax) |
| `git branch -d feature` | Delete merged branch |
| `git branch -D feature` | Force delete |
| `git stash` | Save dirty state |
| `git stash pop` | Restore stash |

</CheatSection>

<CheatSection title="Merging & Rebase">

| Command | What it does |
|---------|-------------|
| `git merge feature` | Merge into current branch |
| `git merge --no-ff feature` | Force merge commit |
| `git rebase main` | Replay commits on top of main |
| `git rebase -i HEAD~3` | Interactive rebase (last 3 commits) |
| `git cherry-pick <sha>` | Copy single commit |

</CheatSection>

<CheatSection title="Remote">

| Command | What it does |
|---------|-------------|
| `git remote -v` | List remotes |
| `git fetch origin` | Fetch without merging |
| `git pull origin main` | Fetch + merge |
| `git push -u origin feature` | Push + set upstream |
| `git push --force-with-lease` | Safe force push |

</CheatSection>

<CheatSection title="Undoing Things">

| Command | What it does |
|---------|-------------|
| `git restore file` | Discard working tree changes |
| `git restore --staged file` | Unstage file |
| `git reset HEAD~1` | Undo last commit, keep changes staged |
| `git reset --hard HEAD~1` | Undo last commit, discard changes |
| `git revert <sha>` | New commit that undoes a commit |
| `git reflog` | Show all HEAD positions (recovery) |

</CheatSection>
